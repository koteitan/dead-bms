# BM1.1 の停止しない例（hyp cos）

| bad root 探索 | bad part 上昇 | 上昇改変 | $`f(n)`$ |
|---|---|---|---|
| 上行枝無視方式 | 全枝有効方式 | 改変なし | $`n^2`$ |

## 主張

$`M =`$ `(0,0,0)(1,1,1)(2,0,0)(1,1,1)` とします。

**定理**（[Main.lean](../../lean/BM1.1/Main.lean) の `DeadBms.BM1_1.Ex.main`）

1. $`M`$ は BM1.1 の標準形である。
2. 任意の $`n \ge 1`$ について、$`M[n]`$ から始まる計算は停止しない。0 の行を足した $`\mathrm{pad}_4(M)`$ についても同じ。
3. $`M`$ から始まる無限下降列がある。

用語と汎用補題は [doc/README.md](../README.md) にあります。

## 出典

hyp cos, [Talk:Bashicu matrix system](https://googology.fandom.com/wiki/Talk:Bashicu_matrix_system), "Still with problems"（2016-05-23）:

> Continue upward, we get (0,0,0)(1,1,1)(2,0,0)(1,1,0)(2,2,1)(3,0,0)...(k,k,0)(k+1,k+1,1)(k+2,0,0)(k+1,k+1,1), and we can never solve (0,0,0)(1,1,1)(2,0,0)(1,1,1)[n].

出典の 2 周期分の 12 行は、どれも次の 2 点を確かめています（[Trace.lean](../../lean/BM1.1/Trace.lean)）。

- 右辺が展開の接頭辞になっていること
- bad root が、出典に書かれた bad part の先頭の列であること

## 標準形であること

$`(0,0,0,0)(1,1,1,1)`$ から次のブラケットで展開すると $`\mathrm{pad}_4(M)`$ になります（[Standard.lean](../../lean/BM1.1/Standard.lean)）。下の表では最下行の 0 を省いています。

```
    (0,0,0,0)(1,1,1,1)
[2] (0,0,0)(1,1,1)(2,2,2)
[1] (0,0,0)(1,1,1)(2,2,1)
[1] (0,0,0)(1,1,1)(2,2,0)(3,3,1)
[0] (0,0,0)(1,1,1)(2,2,0)
[1] (0,0,0)(1,1,1)(2,1,1)
[1] (0,0,0)(1,1,1)(2,1,0)(3,2,1)
[0] (0,0,0)(1,1,1)(2,1,0)
[1] (0,0,0)(1,1,1)(2,0,0)(3,1,1)
[1] (0,0,0)(1,1,1)(2,0,0)(3,1,0)
[1] (0,0,0)(1,1,1)(2,0,0)(3,0,0)
[1] (0,0,0)(1,1,1)(2,0,0)(2,0,0)
[1] (0,0,0)(1,1,1)(2,0,0)(1,1,1)(2,0,0)
[0] (0,0,0)(1,1,1)(2,0,0)(1,1,1)
```

## ループ

次のように置きます。

- $`T_j = (j,j,0)(j+1,j+1,1)(j+2,0,0)`$
- $`Q_k = T_0 T_1 \cdots T_k`$
- $`E_k = (k+1,k+1,0)(k+2,k+2,1)`$

このとき $`Q_{k+1} = Q_k E_k (k+3,0,0)`$ です。1 周期は次の 6 つの行列からなり、$`s_0(0) = M`$ です。

| 段階 | 行列 | $`t`$ | bad root | 次の行列 |
|---|---|---|---|---|
| $`s_0(k)`$ | $`Q_k\ (k+1,k+1,1)`$ | 3 | $`T_k`$ の先頭 $`(k,k,0)`$ | $`s_1(k)`$ |
| $`s_1(k)`$ | $`Q_k E_k\ (k+3,1,0)`$ | 2 | 列 1 の $`(0,0,0)`$ | $`s_2(k)`$ |
| $`s_2(k)`$ | $`Q_k E_k (k+3,0,0)\ (k+4,1,1)`$ | 3 | $`(k+3,0,0)`$ | $`s_3(k)`$ |
| $`s_3(k)`$ | $`Q_k E_k (k+3,0,0)\ (k+4,1,0)`$ | 2 | $`(k+3,0,0)`$ | $`s_4(k)`$ |
| $`s_4(k)`$ | $`Q_k E_k (k+3,0,0)\ (k+4,0,0)`$ | 1 | $`(k+3,0,0)`$ | $`s_5(k)`$ |
| $`s_5(k)`$ | $`Q_k E_k (k+3,0,0)\ (k+3,0,0)`$ | 1 | $`(k+2,k+2,1)`$ | $`s_0(k+1)`$ |

全枝有効方式なので $`B_1 = B + \Delta`$ です。各段階の $`\Delta`$ と $`B_1`$ の先頭は次のとおりで、どの段階でも次の行列は $`n \ge 1`$ のときの展開の接頭辞になります。

- **$`s_0(k)`$**: bad root を求めます。
  - 1 行目: 左にあって 1 行目が $`k+1`$ より小さい最も右の列は、$`T_k`$ の先頭 $`(k,k,0)`$ です。
  - 2 行目: $`(k,k,0)`$ の 2 行目 $`k`$ は $`k+1`$ より小さいので、2 行目の親も同じ列です。
  - 3 行目: 3 行目 $`0`$ は $`1`$ より小さいので、3 行目の親も同じ列です。

  $`B = T_k`$、$`\Delta = (1,1,0)`$、$`B_1 = (k+1,k+1,0)(k+2,k+2,1)(k+3,1,0)`$ となり、$`s_0(k)^- B_1 = s_1(k)`$ です。
- **$`s_1(k)`$**: bad root は列 1 です（後述）。$`B = s_1(k)^-`$、$`\Delta = (k+3,0,0)`$ で、$`B_1`$ は $`(k+3,0,0)(k+4,1,1)\cdots`$ と始まります。
- **$`s_2(k)`$, $`s_3(k)`$, $`s_4(k)`$**: すぐ左の $`(k+3,0,0)`$ は、どの行でも最右列より小さいので bad root になります。$`\Delta`$ はそれぞれ $`(1,1,0)`$、$`(1,0,0)`$、$`(0,0,0)`$ で、$`B_1`$ はそれぞれ $`(k+4,1,0)`$、$`(k+4,0,0)`$、$`(k+3,0,0)`$ です。
- **$`s_5(k)`$**: $`(k+3,0,0)`$ は 1 行目が等しいので bad root になりません。その左の $`(k+2,k+2,1)`$ が bad root です。$`\Delta = 0`$ なので $`B_1 = (k+2,k+2,1)(k+3,0,0)`$ で、$`s_5(k)^-\,(k+2,k+2,1) = Q_{k+1}\,(k+2,k+2,1) = s_0(k+1)`$ です。

### $`s_1(k)`$ の bad root が列 1 であること

最右列 $`(k+3,1,0)`$ の 1 行目の先祖をたどります。1 行目の親は「左にあって 1 行目がより小さい最も右の列」です。

$`(j+2,0,0)`$ の形の列（2 行目が 0）は、すぐ右に 1 行目がより小さい $`(j+1,j+1,0)`$ があります。そのため $`(j+2,0,0)`$ は、どの列の 1 行目の親にもなりません。

- 右隣 $`(j+1,j+1,0)`$ 自身からは、$`(j+2,0,0)`$ は小さくないので親になりません。
- それより右の列からは、$`(j+1,j+1,0)`$ のほうが先に見つかります。

したがって、最右列の 1 行目の先祖のうち列 1 以外は、2 行目が $`1 = c_2`$ 以上です。列 1 の $`(0,0,0)`$ は先祖に含まれます（1 行目が 0 なので、先祖をたどると必ずここに着きます）。よって 2 行目の親は列 1 です。

Lean では、この「直後の列が小さければ親にならない」という論法を `findLastIdx_take_ne` で、隣り合う列の性質を `Adj` で扱っています。
