# BM3 の停止しない例（Alemagno12）

| bad root 探索 | bad part 上昇 | 上昇改変 | $`f(n)`$ |
|---|---|---|---|
| 上行枝無視方式 | BM3 方式 | 改変なし | $`n^2`$ |

## 主張

$`M =`$ `(0,0,0)(1,1,1)(2,1,1)(1,1,1)` とします。

**定理**（[Main.lean](../../lean/BM3/Main.lean) の `DeadBms.BM3.Ex.main`）

1. $`M`$ は BM3 の標準形である。
2. 任意の $`n \ge 1`$ について、$`M[n]`$ から始まる計算は停止しない。0 の行を足した $`\mathrm{pad}_4(M)`$ についても同じ。
3. $`M`$ から始まる無限下降列がある。

用語と汎用補題は [doc/README.md](../README.md) にあります。

## 出典

Alemagno12, [User blog:Alemagno12/BM3 has an infinite loop](https://googology.fandom.com/wiki/User_blog:Alemagno12/BM3_has_an_infinite_loop)（2018-06-29）。

出典は、まず $`(0,0,0,0)(1,1,1,1)`$ から $`M`$ が標準形であることを示し、次に次の列が無限に続くことを示しています。

```
(0,0,0)(1,1,1)(2,1,1)(1,1,0)(2,2,1)(3,1,1)
(0,0,0)(1,1,1)(2,1,1)(1,1,0)(2,2,1)(3,1,0)(4,2,1)(5,1,1)
…
```

後半の各行は [Trace.lean](../../lean/BM3/Trace.lean) で再現しています。

出典の 3 行目には `…(7,3,1)(8,1,1)(9,3,0)…` とありますが、定義どおりの展開は `…(7,3,1)(8,1,1)(7,3,0)(8,4,1)(9,3,0)…` で、2 列が抜けています。証明に使うのはこの部分より前の接頭辞なので、結論には影響しません。

## ループ

$`k \ge 0`$ について次の族を考えます。$`X_0 = M`$ です。

```math
X_k = (0,0,0)(1,1,1)(2,1,1)\ \prod_{j=0}^{k-1} (2j+1,1,0)(2j+2,2,1)\ (2k+1,1,1)
```

### bad root が列 1 であること

最右列は $`C = (2k+1, 1, 1)`$ で、$`t = 3`$ です。$`X_k`$ は次の性質を持ちます。

- 列 1 は $`(0,0,0)`$ である。
- 列 1 以外のすべての列は 1 行目が正である。
- 列 1 と最右列以外のすべての列は 2 行目が $`1 = c_2`$ 以上である。
- $`c_2, c_3 \gt  0`$ である。

このとき、上行枝無視方式の bad root は列 1 です（[Ubim.lean](../../lean/Common/Ubim.lean) の汎用定理 `ubim_eq_zero`）。

1. 1 行目の先祖をたどると、必ず列 1 に着きます。
2. その途中の列はどれも 2 行目が $`c_2`$ 以上なので、2 行目の親は列 1 です。
3. 3 行目の親も列 1 です。

### 展開

$`B = X_k^-`$、$`\Delta = (2k+1, 1, 0)`$ です。$`B`$ の先頭 3 列 $`(0,0,0)(1,1,1)(2,1,1)`$ の BM3 方式のフラグは次のとおりです。

- $`(0,0,0)`$: すべて 1
- $`(1,1,1)`$: すべて 1
- $`(2,1,1)`$: 1 行目は 1、2 行目は 0（$`p = (1,1,1)`$ の 2 行目 $`1`$ が $`1`$ より小さくないため）

$`B_1`$ の先頭 3 列は $`(2k+1,1,0)(2k+2,2,1)(2k+3,1,1)`$ です。よって $`n \ge 1`$ について次が成り立ちます。

```math
X_k[n] = X_k^-\ (2k+1,1,0)(2k+2,2,1)(2k+3,1,1) \cdots = X_{k+1} \cdots
```

$`X_{k+1}`$ は $`X_k[n]`$ の接頭辞なので、汎用補題により $`M = X_0`$ から始まる計算は停止しません。
