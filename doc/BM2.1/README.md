# BM2.1 の停止しない例

| bad root 探索 | bad part 上昇 | 上昇改変 | $`f(n)`$ |
|---|---|---|---|
| 上行枝無視方式 | 全枝有効方式 | 改変なし | $`n+1`$ |

分類ページには「停止しない」「BM1.1と同じ」とあります。BM2.1 の展開規則は BM1.1 と同じで、違うのは $`f(n) = n + 1`$ だけです。そこで [BM1.1 の例](../BM1.1/README.md) を使います。

ページにある KurohaKafka の例は Twitter 上にあり確認できなかったので、扱っていません。

## 主張

$`M =`$ `(0,0,0)(1,1,1)(2,0,0)(1,1,1)` とします。

**定理**（[Main.lean](../../lean/BM2.1/Main.lean) の `DeadBms.BM2_1.Ex.main`）

1. $`M`$ は BM2.1 の標準形である。
2. 任意の $`n \ge 1`$ について、$`M[n]`$ から始まる計算（$`f(n) = n+1`$）は停止しない。0 の行を足した $`\mathrm{pad}_4(M)`$ についても同じ。
3. $`M`$ から始まる無限下降列がある。

## 証明

- 展開は BM1.1 と同じです（`expand_eq`、`rfl`）。よって標準形の経路と、ループの族 $`S`$ の条件はそのまま移ります（`Std.of_expand_eq`、`Loop.of_expand_eq`）。
- 汎用補題の残りの条件は「$`n \ge 1 \Rightarrow f(n) \ge 1`$」で、$`f(n) = n + 1`$ なので成り立ちます。
