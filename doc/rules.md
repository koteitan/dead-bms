# 分類ページの規則と Lean の定義

分類ページで「停止しない」と書かれている 7 つのルールセットを対象にします。いずれも上昇改変ルールは「改変なし」で、上昇フラグは $`a_{xy} = a'_{xy}`$ です。

| ルールセット | bad root 探索 | bad part 上昇 | $`f(n)`$ | Lean |
|---|---|---|---|---|
| BM1 | 左隣法 | 全枝有効方式 | $`n^2`$ | `BM1` |
| rTSS | 左隣法 | 全枝有効方式 | $`n^2`$ | `rTSS` |
| BM1.1 | 上行枝無視方式 | 全枝有効方式 | $`n^2`$ | `BM1_1` |
| BM2.1 | 上行枝無視方式 | 全枝有効方式 | $`n+1`$ | `BM2_1` |
| Bubby3's fix | 上行枝無視方式 | 全枝有効方式 | $`n^2`$ | `Bubby3fix` |
| BM2 | 上行枝無視方式 | BM2 方式 | $`n^2`$ | `BM2` |
| BM3 | 上行枝無視方式 | BM3 方式 | $`n^2`$ | `BM3` |

定義は [Rules.lean](../lean/Common/Rules.lean)、[BadRoot.lean](../lean/Common/BadRoot.lean)、[Ascend.lean](../lean/Common/Ascend.lean)、[Expand.lean](../lean/Common/Expand.lean) にあります。

次のルールセットは対象外です。分類ページには「壊れている」「停止しないと予想」とだけ書かれ、停止しないとは書かれていないためです。

- BM3.1、BM3.2、BM3.1.1
- 停止しないとの記述がないもの: BM4、BM2.3、BM2.2

## bad root 探索

- **左隣法**（`leftAdj`）: $`C`$ より左にあり、行 $`t`$ とそれより上のすべての行 $`y \le t`$ で $`m_y \lt  c_y`$ を満たす列 $`M`$ のうち、最も右のもの。
- **上行枝無視方式**（`parent`, `ubim`）: 要素 $`c`$ の親は、次をすべて満たす最も右の要素 $`m`$ です。
  - $`c`$ と同じ行にある
  - $`c`$ より左にある
  - $`c`$ より小さい
  - 最上行にあるか、または $`c`$ のひとつ上の要素の先祖のどれかと同じ列にある

  $`c`$ 自身と、$`c`$ の先祖の親を、$`c`$ の先祖と呼びます。bad root は $`c_t`$ の親がいる列です。

## bad part 上昇ルール

$`B = (b_{xy})`$ の列 $`x = 1`$ が bad root です。$`p(x) = \max\lbrace k \mid k \lt  x \land b_{k1} \lt  b_{x1}\rbrace`$ と置きます。

- **全枝有効方式**（`ascAll`）: $`a'_{xy} = 1`$。
- **BM2 方式**（`ascBM2`）: $`a'_{1y} = 1`$。$`x \gt  1`$ では $`a'_{xy} = 1 \iff a'_{p(x)y} = 1 \land r_y \lt  b_{xy}`$。
- **BM3 方式**（`ascBM3`）: $`a'_{x1} = 1`$、$`a'_{1y} = 1`$。$`x \gt  1`$ では $`a'_{xy} = 1 \iff a'_{p(x)y} = 1 \land b_{p(x)y} \lt  b_{xy}`$。

$`p(x)`$ がない場合は $`a'_{xy} = 0`$ とします。

## ページの記述の解釈

ページの式をそのまま読むと意味が通らない箇所が 3 つあり、次のように読みました。どの読み方も、出典のトレースまたは yaBMS との照合で確かめています。

1. **左隣法の不等号**: ページは「$`m_y \gt  c_y`$」と書いていますが、$`m_y \lt  c_y`$ と読みました。hyp cos と Bubby3 の BM1 のトレース（[BM1/1/Trace.lean](../lean/BM1/1/Trace.lean)、[BM1/2/Trace.lean](../lean/BM1/2/Trace.lean)）と一致します。
2. **BM2 方式の $`b_{r_y y}`$**: ページは「$`b_{r_y y} \lt  b_{xy}`$」と書いていますが、bad root の $`y`$ 行目の $`r_y`$ と読みました。Bubby3 の BM2 のトレース（[BM2/Trace.lean](../lean/BM2/Trace.lean)）と yaBMS `-v 2` の出力 144 件と一致します。
3. **BM3 方式の向き**: 本文の説明は「$`b_{xy}`$ が $`b_{p(x)y}`$ よりも小さい」ですが、式は $`b_{p(x)y} \lt  b_{xy}`$ です。式のほうを採用しました。Alemagno12 のトレース（[BM3/Trace.lean](../lean/BM3/Trace.lean)）と一致します。

## そのほかの注

4. **BM3 の $`f`$**: ページには書かれていません。BM3 の BASIC コードにある `A=A*A` から $`f(n) = n^2`$ としました。
5. **rTSS**: BM1 の規則を 3 行の行列に制限したものとして扱います。ページの「BM1 のトリオ数列システムと同じ」によります。
6. **BM2.1 と Bubby3's fix**: BM1.1 と同じ展開規則です（ページの「BM1.1 と同じ」）。BM2.1 は $`f(n) = n + 1`$ である点だけが違います。BM2.1 の KurohaKafka の例は Twitter にあり確認できなかったので、BM1.1 の例で示します。
7. **ブラケットの更新**: ページの手順では、[n] を [f(n)] に変えたあと「ブラケット $`n`$ の値に従って」コピーします。どちらの値でコピーするかははっきりしません。Lean の `compute` は新しい値 $`f(n)`$ だけコピーしています。汎用補題はブラケットが 1 以上なら成り立つので、どちらの読み方でも結論は同じです。
8. **0 の行**: 標準形の経路は 1 行多い $`\iota_{N+1}`$ から始まります。0 の行を足しても展開と停止性が変わらないことを証明しています（[README.md](README.md) の「標準形」）。
