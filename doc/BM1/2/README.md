# BM1 の停止しない例 2（Bubby3）

## 主張

$`M =`$ `(0,0)(1,1)(2,2)(3,0)(2,1)(3,1)(4,1)` とします。

**定理**（[Main.lean](../../../lean/BM1/2/Main.lean) の `DeadBms.BM1.Ex2.main`）

1. $`M`$ は BM1 の標準形である。
2. 任意の $`n \ge 1`$ について、$`M[n]`$ から始まる計算は停止しない。0 の行を足した $`\mathrm{pad}_3(M)`$ についても同じ。
3. $`M`$ から始まる無限下降列がある。

用語と汎用補題は [doc/README.md](../../README.md) にあります。

## 出典

Bubby3, [User blog:Bubby3/BM1 is weaker than expected.](https://googology.fandom.com/wiki/User_blog:Bubby3/BM1_is_weaker_than_expected.)（2018-03）:

> (0,0)(1,1)(2,2)(3,0)(2,1)(3,1)(4,1) decomposes into (0,0)(1,1)(2,2)(3,0)(2,1)(3,1)(4,0)(3,1)(4,1)(5,0)(4,1)(5,1)(6,0)(5,1)(6,1)..., which eventually becomes (0,0)(1,1)(2,2)(3,0)(2,1)(3,1)(4,0)(3,1)(4,1)(5,0)(4,1), which just keeps escalating forever when it encontours a (4,1).

この展開は [Trace.lean](../../../lean/BM1/2/Trace.lean) で再現しています。

BM1 の 2 行版は、ペア数列システム（PSS）とは bad root が違います。この $`M`$ について、BM1 の bad root は $`(3,0)`$、BM4 の bad root は $`(0,0)`$ です。

## 標準形であること

$`(0,0,0)(1,1,1)`$ から次のブラケットで展開すると $`\mathrm{pad}_3(M)`$ になります（[Standard.lean](../../../lean/BM1/2/Standard.lean)）。下の表では最下行の 0 を省いています。

```
    (0,0,0)(1,1,1)
[3] (0,0)(1,1)(2,2)(3,3)
[1] (0,0)(1,1)(2,2)(3,2)
[1] (0,0)(1,1)(2,2)(3,1)(4,2)
[0] (0,0)(1,1)(2,2)(3,1)
[1] (0,0)(1,1)(2,2)(3,0)(4,1)(5,2)
[0] (0,0)(1,1)(2,2)(3,0)(4,1)
[1] (0,0)(1,1)(2,2)(3,0)(4,0)
[1] (0,0)(1,1)(2,2)(3,0)(3,0)
[1] (0,0)(1,1)(2,2)(3,0)(2,2)(3,0)
[0] (0,0)(1,1)(2,2)(3,0)(2,2)
[1] (0,0)(1,1)(2,2)(3,0)(2,1)(3,2)(4,0)
[0] (0,0)(1,1)(2,2)(3,0)(2,1)(3,2)
[2] (0,0)(1,1)(2,2)(3,0)(2,1)(3,1)(4,1)
```

## ループ

$`k \ge 0`$ について次の族を考えます。$`X_0 = M`$ です。

```math
X_k = P\ ((4,0)(3,1))^k\ (4,1), \qquad P = (0,0)(1,1)(2,2)(3,0)(2,1)(3,1)
```

$`X_k`$ の展開は次のとおりです。

1. 最右列は $`C = (4,1)`$ で、$`t = 2`$ です。
2. 左隣法の bad root は、$`m_1 \lt  4`$ かつ $`m_2 \lt  1`$ を満たす最も右の列です。
   - 繰り返し部分の $`(4,0)`$ は $`m_1 = 4`$、$`(3,1)`$ は $`m_2 = 1`$ なので満たしません。
   - $`P`$ の中でも $`(3,1)`$ と $`(2,1)`$ は満たさず、左から 4 番目の $`(3,0)`$ が満たします。
   - よって bad root は、$`k`$ によらず $`R = (3,0)`$ です。
3. bad part は $`B = (3,0)(2,1)(3,1)\ ((4,0)(3,1))^k`$、$`\Delta = (1,0)`$ です。
4. 全枝有効方式なので $`B_1 = (4,0)(3,1)(4,1)\ ((5,0)(4,1))^k`$ です。
5. よって $`n \ge 1`$ について次が成り立ちます。

```math
X_k[n] = P\ ((4,0)(3,1))^k\ (4,0)(3,1)(4,1) \cdots = X_{k+1} \cdots
```

$`X_{k+1}`$ は $`X_k[n]`$ の接頭辞なので、汎用補題により $`M = X_0`$ から始まる計算は停止しません。

Bubby3 の「eventually becomes (0,0)(1,1)(2,2)(3,0)(2,1)(3,1)(4,0)(3,1)(4,1)(5,0)(4,1)」は、$`X_1 = P\,(4,0)(3,1)\,(4,1)`$ を接頭辞に持つ行列です。
