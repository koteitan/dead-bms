# BM1 の停止しない例 1（hyp cos）

## 主張

$`M =`$ `(0,0,0)(1,1,1)(2,0,0)(1,1,0)(2,1,0)(3,1,0)` とします。

**定理**（[Main.lean](../../../lean/BM1/1/Main.lean) の `DeadBms.BM1.Ex1.main`）

1. $`M`$ は BM1 の標準形である。
2. 任意の $`n \ge 1`$ について、$`M[n]`$ から始まる計算は停止しない。0 の行を足した $`\mathrm{pad}_4(M)`$ についても同じ。
3. $`M = X_0, X_1, X_2, \dots`$ で、各 $`X_{i+1}`$ が $`X_i`$ のある展開に等しい無限列がある。

用語と汎用補題は [doc/README.md](../../README.md) にあります。

## 出典

hyp cos, [Talk:Bashicu matrix system](https://googology.fandom.com/wiki/Talk:Bashicu_matrix_system), "Something wrong happens"（2016-04-28）:

> (0,0,0)(1,1,1)(2,0,0)(1,1,0)(2,1,0)(3,1,0)[n] reduces to (0,0,0)(1,1,1)(2,0,0)(1,1,0)(2,1,0)(3,0,0)(2,1,0)(3,1,0)...[n], where (0,0,0)(1,1,1)(2,0,0)(1,1,0)(2,1,0)(3,0,0)(2,1,0)(3,1,0)[n1] reduces to …

## ループ

$`k \ge 0`$ について次の族を考えます。$`X_0 = M`$ です。

```math
X_k = P\ ((3,0,0)(2,1,0))^k\ (3,1,0), \qquad P = (0,0,0)(1,1,1)(2,0,0)(1,1,0)(2,1,0)
```

$`X_k`$ の展開は次のとおりです。

1. 最右列は $`C = (3,1,0)`$ で、$`t = 2`$ です。
2. 左隣法の bad root は、$`m_1 \lt  3`$ かつ $`m_2 \lt  1`$ を満たす最も右の列です。
   - 繰り返し部分の $`(3,0,0)`$ は $`m_1 = 3`$、$`(2,1,0)`$ は $`m_2 = 1`$ なので満たしません。
   - $`P`$ の中でも $`(2,1,0)`$ と $`(1,1,0)`$ は $`m_2 = 1`$ で満たさず、左から 3 番目の $`(2,0,0)`$ が満たします。
   - よって bad root は、$`k`$ によらず $`R = (2,0,0)`$ です。
3. bad part は $`B = (2,0,0)(1,1,0)(2,1,0)\ ((3,0,0)(2,1,0))^k`$、$`\Delta = (3-2, 0, 0) = (1,0,0)`$ です。
4. 全枝有効方式なので $`B_1 = B + (1,0,0) = (3,0,0)(2,1,0)(3,1,0)\ ((4,0,0)(3,1,0))^k`$ です。
5. よって $`n \ge 1`$ について次が成り立ちます。

```math
X_k[n] = X_k^-\ B_1 \cdots = P\ ((3,0,0)(2,1,0))^k\ (3,0,0)(2,1,0)(3,1,0) \cdots = X_{k+1} \cdots
```

$`X_{k+1}`$ は $`X_k[n]`$ の接頭辞です。$`S = \lbrace X_k \mid k \ge 0 \rbrace`$ は汎用補題の条件を満たすので、$`M = X_0`$ から始まる計算は停止しません。
